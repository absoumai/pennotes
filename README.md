# PenNotes

Handwrite on an iPad with the Apple Pencil. The page sends the strokes to Claude,
which reads the handwriting, and a bar at the bottom of the note asks what you want:
explain simple, quiz me, summarise, flashcards, solve step by step, check my work.

Just one static page. It talks to a small API that holds the Claude key, so no
credentials live here. Passcode-gated, typed once per device.

Open it: https://absoumai.github.io/pennotes/
